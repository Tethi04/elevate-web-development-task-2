# ⚡ AuraTasks — Dynamic To-Do Web App

A sleek, responsive To-Do List web application featuring real-time task state updates, progress tracking, dynamic task filtering, local storage persistence, and a modern glassmorphism design system.

Built as part of **Task 2** for the **Elevate Labs Web Development Internship**[span_2](start_span)[span_2](end_span).

## ✨ Key Features

* **Instant DOM Updates:** Add, toggle completion, and delete tasks dynamically without reloads[span_3](start_span)[span_3](end_span).
* **Local Storage Persistence:** Remembers all your tasks and completed status across page refreshes.
* **Progress Tracker:** Visual progress bar calculating task completion percentages in real time.
* **Dynamic Task Filtering:** Filter tasks instantly by `All`, `Active`, and `Completed` tabs.
* **Event Delegation:** Optimized performance using single event listeners on list parents[span_4](start_span)[span_4](end_span).
* **Glassmorphic UI:** Aesthetic dark backdrop glow, responsive layout, and custom animations.
